Your Zim Bindings

Ctrl-jMove down 5 lines.
Ctrl-kMove up 5 lines.
Ctrl-hMove left 5 characters.
Ctrl-lMove right 5 characters.
FFLeave insert mode.
Ctrl-pToggle paste mode.
Meta-hMove to split on the left.
Meta-jMove to split below.
Meta-kMove to split above.
Meta-lMove to split on the right.
These are repo-owned mappings from share/configs/zim/lua/mappings.lua. They override or add to NVChad defaults.

Buffers, Tabs, Windows

HPrevious buffer/file.
LNext buffer/file.
Ctrl-tCreate a new real Neovim tab.
TabNext real Neovim tab.
Shift-TabPrevious real Neovim tab.
Space xClose the current buffer/file.
:qClose the current window/split.
Ctrl-w h/j/k/lNative split navigation.
:spCreate a horizontal split.
:vspCreate a vertical split.
Ctrl-w wCycle between windows.
:qaQuit all windows.
Model: buffers are files, windows are panes, tabs are workspaces. Use H/L for files most of the time.

Common Workflows

Open A Project
zim .

Then use Ctrl-n for the tree or Space ff for file search.

Switch Files
H L

Use buffers for files. Use real tabs only when you want separate workspace layouts.

Open From Tree
Ctrl-n Enter

Tab previews from the tree. Enter opens the file as a normal buffer.

Search The Repo
Space fw

Use live grep for text search. Press Ctrl-c to cancel the picker.

Terminal Flow
Space h

Leave terminal mode with Ctrl-\ Ctrl-n; press i to re-enter.

First Launch
q

If Lazy.nvim opens while installing plugins, wait for completion and press q. Restart zim if needed.

Gotchas: Leader is Space, not backslash. :q closes a window; Space x closes a buffer. :E is not the file tree in this profile; use Ctrl-n or Space e. In nvim-tree, Tab previews; Enter opens normally. Icon boxes usually mean your local terminal is not using a Nerd Font.
